CARA MENGGUNAKAN FILE INI UNTUK GITHUB:

1. Folder ini adalah ROOT (bagian luar) dari repository GitHub Anda.
2. File index.html, manifest.json, dan sw.js di folder luar ini SUDAH SIAP digunakan sebagai PWA.
3. Anda akan melihat 6 folder aplikasi:
   - loader
   - mixer
   - p2h
   - monitoring
   - dashboard-pakan-pwa-v10-industrial-enterprise
   - fmv25 (BARU)
4. PENTING: Masukkan file index.html dan aset aplikasi asli Anda ke dalam masing-masing folder tersebut.
5. SANGAT PENTING: Pastikan Anda MENGHAPUS file manifest.json dan sw.js dari DALAM folder-folder tersebut (termasuk di dalam fmv25). PWA hanya boleh berjalan dari luar (root) agar semuanya menjadi 1 aplikasi di HP.
